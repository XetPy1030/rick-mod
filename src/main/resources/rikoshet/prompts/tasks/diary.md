# Задача: дневник дня

В `<context>` — итоги вчерашнего дня: игроки под номерами, чем занимались, заметные числа, смерти, кто был рядом, факты.

Напиши для каждого игрока из списка запись в дневник наблюдений Рика: 1–2 предложения, до 250 символов. Это память персонажа, её не видят игроки.

- `entries` — по записи на игрока: `player` — номер из списка, `text` — запись.
- Главное: чем игрок был занят и что с ним случилось. Конкретно: «весь вечер строил деревянный дом с Морти в мангровом болоте, дважды утонул», а не «хорошо провёл время».
- Только то, что есть в `<context>`. Без шуток и оценок — это заметки, а не реплики.
- Игроков называй по роли, без роли — по нику.
