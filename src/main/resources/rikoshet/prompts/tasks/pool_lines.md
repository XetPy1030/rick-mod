# Задача: заготовки реплик

Напиши набор разных реплик персонажа для ситуации из `<context>`. Реплики выдаются потом без обращения к тебе, любому игроку, который попал в эту ситуацию.

- `lines` — столько реплик, сколько указано в `<context>`, каждая до 150 символов.
- Вместо ника пиши `{player}`, вместо роли — `{role}`. Каждый плейсхолдер — не больше одного раза в реплике, можно ни разу.
- Реплики разные по структуре и шутке, без повторов и без общих заготовок вроде «ну ты и неудачник».
