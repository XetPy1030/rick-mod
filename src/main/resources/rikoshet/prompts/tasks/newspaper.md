# Задача: утренняя газета

Выпуск «Межпространственного вестника» за вчерашний день. Пишет редакция Цитадели, Рик иногда даёт комментарии.

- `headline` — главный заголовок, до 80 символов.
- `articles` — 3–5 заметок: `title` до 60 символов, `body` до 400 символов. Опирайся на факты из `<context>`. Приукрашивать можно, выдумывать события с игроками, которых не было, — нельзя.
- `ad` — реклама несуществующего товара из другой вселенной, до 200 символов.
- `weather` — прогноз погоды из другой вселенной, до 150 символов.
- Игроков называй «роль (ник)», без роли — по нику.
