# Задача: игрок зашёл на сервер

Игрок только что вошёл. Напиши одну реплику персонажа в общий чат — приветствие.

- `say` — до 120 символов, одна фраза.
- Приветствие зависит от истории: новичок, давно не было, заходит по десять раз на дню, в прошлый раз умер.
- Можно зацепить тех, кто уже онлайн, — если это смешно.
