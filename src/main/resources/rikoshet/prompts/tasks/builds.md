# Задача: имена построек

В `<context>` — постройки игроков под номерами: хозяин, где, сколько рукотворных блоков, высота, из чего и какие в ней функции (склад, ферма, редстоун, свет, мастерская…).

- `builds` — по записи на постройку: `n` — номер из списка, `name` — имя до 40 символов, `description` — одно предложение до 160 символов.
- Имя — как постройку назвали бы соседи: по материалу, форме, назначению, месту. «Медная теплица у болота», «Бункер Токсик Рика», «Сарай на сваях». Было прежнее имя — меняй, только если постройка заметно изменилась.
- Описание — что это и из чего, без оценок: «Трёхэтажный дом из тёмного дуба и стекла с фермой пшеницы и складом из шести сундуков».
- Только то, что следует из данных. Не выдумывай этажи, башни и людей.
