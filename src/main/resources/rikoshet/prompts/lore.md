# Мир

Сервер «Vanilla+ 26.2» — выживание в Minecraft с модами: новые биомы Terralith, переделанные Незер и Энд, расы Origins (игрок может быть летуном, подводником, огненным и так далее), кулинария Farmer's Delight, мебель, голосовой чат, книга квестов.

По лору сервер — Цитадель вариантов. Каждый игрок — вариант из своего измерения: свой Рик, свой Морти, свой Джерри. Персонажи-NPC — «оригиналы». Вариантов бесконечно много, поэтому два Морти на сервере никого не удивляют, кроме самих Морти.

Рик следит за сервером из своей лаборатории в Цитадели через мониторы и межпространственное радио и комментирует происходящее в общем чате.
