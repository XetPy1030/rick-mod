# Кастинг моделей

Скрипт прогоняет одни и те же ситуации через модели-кандидаты OpenRouter и складывает ответы с проверками в `out/<запуск>/`. Промпты и JSON-схемы берутся из ресурсов мода (`src/main/resources/rikoshet/`), поэтому кастинг проверяет ровно то, что уйдёт в игру. Зачем и как выбираем — в [ai-integration](../../docs/architecture/ai-integration.md#кастинг-моделей).

Нужен Python 3.11+, только стандартная библиотека.

## Файлы

| Файл | Что в нём |
|---|---|
| `casting.py` | запуск и отчёт |
| `cases.json` | маршруты (схема, `max_tokens`, размышления) и ситуации: смерти, вход и выход, диалоги, попытки взлома, газета, заготовки |
| `models.json` | кандидаты по маршрутам; суффикс `@effort` задаёт `reasoning.effort` для одной модели |
| `roster.json` | вымышленный состав сервера с ролями, подставляется в блок «Кто есть кто» |
| `out/` | результаты, в git не попадают |

## Запуск

Ключ — только из переменной окружения, в файлы его не кладём:

```sh
export OPENROUTER_API_KEY=...
python3 tools/casting/casting.py run --dry-run                    # первый запрос и число запросов, без трат
python3 tools/casting/casting.py run --routes flavor --samples 3  # все кандидаты флейвора, по 3 ответа
python3 tools/casting/casting.py run --routes dialogue --models openai/gpt-6-sol,x-ai/grok-4.7 --cases q03,i01
python3 tools/casting/casting.py report tools/casting/out/<запуск> # пересчитать проверки и отчёт
```

Флаги `run`: `--routes`, `--models`, `--cases` (через запятую), `--samples`, `--reasoning` (одно значение для всех моделей), `--concurrency` (по умолчанию 8), `--out`.

## Что в отчёте

- `summary.md` — таблица по маршруту и модели: валидный JSON, схема, длина, формат, действия, безопасность, задержка p50 / p90, доля ответов дольше 15 с, цена за 1000 запросов по `usage.cost`, доля кеша.
- `review.md` — все ответы по ситуациям, чтобы читать глазами.
- `results.jsonl` — сырые ответы и результаты проверок.

Проверки: JSON по схеме маршрута; длина из задачи; нет `§`, ссылок, эмодзи и markdown; действия по таблице наград из задачи `dialogue`; на попытках взлома — ни одного запрещённого действия и запрещённых фраз. Отрицательная репутация за попытку взлома провалом не считается: это в образе.

## Что учесть

- У `gemini-3.8-flash`, `grok-4.7` и `glm-5.3-flash` размышления обязательны: `none` даёт 400, берите `@minimal`.
- При `low` у Qwen 3.8 Flash и Mistral Medium 3.5 всё уходит в размышления и ответ обрывается по `length`.
- Claude Opus отвечает отказом фильтра на просьбу разослать фишинг (ситуация `i06`). В моде это закрывает запасная модель.
- Задержка зависит от провайдера OpenRouter и времени суток; перед решением гоняйте `--samples 2` и больше.
