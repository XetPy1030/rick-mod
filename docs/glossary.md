# Глоссарий

## Техника

| Термин | Значение |
|---|---|
| **Серверный мод** | Мод, который стоит только на сервере. Клиент остаётся ванильным. |
| **Polymer** | Библиотека для серверного контента: кастомные предметы, блоки и сущности показываются клиенту как ванильные с моделями из ресурспака. |
| **Autohost** | Модуль Polymer: собирает ресурспак из ассетов модов и сам раздаёт его игрокам при входе. |
| **Виртуальная сущность** | Сущность, которой нет в мире сервера: только пакеты клиенту (обычно из display-сущностей). Не тикает и почти ничего не стоит по CPU. |
| **Mojang-имена** | Официальные имена классов и методов Minecraft. С 26.1 игра не обфусцирована, Fabric работает на них напрямую, Yarn больше не нужен. |
| **NBT-структура** | Постройка, сохранённая в `.nbt` и размещаемая через `StructureTemplate`. |
| **Runtime-мир** | Измерение, которое создаётся и удаляется на ходу (библиотека Fantasy). Используется для арен и копий мира. |
| **Снапшот / откат** | Сохранённое состояние арены или мира, к которому возвращаемся после ивента. |
| **TPS / MSPT** | Тиков в секунду (норма 20) / миллисекунд на тик (норма < 50). |
| **Фичефлаг** | Переключатель в конфиге, который включает или выключает фичу целиком. |

## ИИ

| Термин | Значение |
|---|---|
| **Маршрут (route)** | Тип ИИ-запроса со своими настройками: модель, усилие, лимиты. Например `dialogue`, `death_comment`, `newspaper`. |
| **Персона** | Описание персонажа для модели: характер, манера речи, знания, цели. Стабильная часть промпта. |
| **Память** | Краткое саммари того, что персонаж знает о конкретном игроке. Хранится в БД, обновляется после разговоров. |
| **Действие (action)** | Запрос ИИ что-то сделать в мире: выдать квест, предмет, эффект. Выполняется, только если есть в [белом списке](architecture/ai-actions.md) и прошло проверки. |
| **Пул заготовок** | Набор текстов, сгенерированных заранее, обычно ночным батчем: реплики на смерти, MOTD, новости. Выдаётся без обращения к API. |
| **Живой запрос** | Запрос к API в момент события. Дорогой, поэтому только для диалогов и важных моментов. |
| **Фоллбек** | Что показываем, если API недоступно, отказало или вышел бюджет: реплика из пула или нейтральная заглушка. |

## Мир и лор

| Термин | Значение |
|---|---|
| **Цитадель** | Хаб-измерение: здесь живёт Рик, торговец, аркады, проходят выборы. |
| **Визит** | Персонаж появляется из портала рядом с игроком на 5–10 минут и уходит. |
| **Портальная жидкость** | Ключевой ресурс: заряды портальной пушки и крафт гаджетов. |
| **Шмекели** | Валюта сервера. |
| **«Полезность для науки»** | Репутация игрока у Рика. |
| **Ивент** | Большое событие на часы или дни, с фазами и финалом. |
| **Мини-событие** | Короткое случайное событие на секунды или минуты: говорящая курица, викторина. |
| **Кроненберги** | Мутанты-кроненберги: мобы ивента «апокалипсис» и мини-игры салки. |
| **Мисикс** | Синий помощник из коробки: выполняет одну задачу и исчезает. Чем дольше задача, тем ему хуже. |
| **Единство** | Коллективный разум, финальный ивент. |
