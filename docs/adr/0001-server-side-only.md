# 0001. Только серверный мод, контент через Polymer

- **Статус:** принято
- **Дата:** 2026-09-26

## Контекст

Сервер для друзей, не все готовы ставить модлоадер и модпак, а каждое обновление модпака — это ещё и синхронизация версий у всех. При этом нужны кастомные предметы, блоки, модели и персонажи.

## Решение

Мод стоит только на сервере. Кастомный контент регистрируется через Polymer и показывается клиенту как ванильный с моделями из ресурспака. Ресурспак собирается и раздаётся автоматически (Polymer autohost).

## Альтернативы

| Вариант | Плюсы | Минусы |
|---|---|---|
| Клиент + сервер (обычный Fabric-мод) | любые механики, свои интерфейсы, рендер | всем ставить мод, синхронизировать версии |
| Только датапаки и ресурспак | никакого Java-кода | нет ИИ, асинхронности, сложной логики |
| Плагин-сервер (Paper) | много готовых плагинов | не Fabric: экосистема Polymer недоступна |

## Последствия

- Клиенту ничего не нужно ставить ради мода: вход на сервер — IP и принять ресурспак.
- Ограничения: нет своих шейдеров, экранов и клиентских анимаций. Всё строим из ванильных моделей, display-сущностей, частиц и GUI на сундуках ([content-delivery](../architecture/content-delivery.md)).
- Зависимость от Polymer и его обновлений под новые версии игры.

## Дополнение 2026-09-26

Выяснилось, что у игроков уже есть модпак: сервер «Vanilla+ 26.2» раздаёт клиентскую сборку архивом (36 модов). Довод «не все готовы ставить модлоадер» отпал, но решение остаётся в силе по другой причине:

- **Каждое изменение клиентской части — перераздача архива восьмерым.** Это самая болезненная процедура сборки: пока версия у кого-то не совпадает, он не зайдёт. Серверный мод обновляется заменой одного jar на сервере.
- Ресурспак Polymer приходит сам при входе, его версии синхронизирует сервер.
- Клиентские моды сборки нам не нужны, но мы можем опираться на то, что они есть у всех: блоки мебели и дверей в постройках, голосовой чат ([server-integration](../architecture/server-integration.md)).

Итоговое правило: **«Рикошет» ничего не добавляет в клиентскую сборку.**
