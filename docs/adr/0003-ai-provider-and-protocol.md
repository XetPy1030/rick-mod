# 0003. ИИ: провайдер и протокол

- **Статус:** предложено
- **Дата:** 2026-09-26

## Контекст

Персонажи, газета и флейвор строятся на языковой модели в облаке. Нужно: асинхронность без влияния на тик, предсказуемый формат ответа, защита от игроков, которые пытаются уговорить ИИ выдать лишнее, и контроль расходов. Исходный план предлагал `java.net.http.HttpClient` + `CompletableFuture` и JSON-ответы с белым списком действий.

## Решение

1. **Провайдер — Claude API** (Anthropic), через официальный Java SDK `com.anthropic:anthropic-java`, закрытый нашим интерфейсом `AiProvider`.
2. **Ответ — структурированный вывод по JSON-схеме** маршрута: `say`, `actions`, `memory_note` ([ai-integration](../architecture/ai-integration.md#протокол-ответа)).
3. **Действия — только из белого списка** с проверкой параметров в коде ([ai-actions](../architecture/ai-actions.md)).
4. **Асинхронность** — отдельный пул потоков, результат в главный поток через `server.execute(...)`.
5. **Экономия** — ночные пулы через Batch API, кеширование стабильного префикса промпта, лимиты и дневной бюджет.
6. **Модели** — по маршрутам в конфиге; по умолчанию `claude-opus-5` с низким усилием; переход на более дешёвые модели — решение владельца по результатам замеров.

## Альтернативы

| Вариант | Плюсы | Минусы |
|---|---|---|
| Сырой `HttpClient` из JDK вместо SDK | ноль зависимостей, маленький jar | свои типы запросов и ответов, свои ретраи, разбор ошибок, батчи — всё руками |
| Другой облачный провайдер | — | придётся заново проверить структурированный вывод, батчи, кеш; интерфейс `AiProvider` оставляет эту дверь открытой |
| Локальная модель | нет платы за токены | на 3 ядрах сервера не запустить; отдельное железо дороже API |
| Свободный текст вместо JSON | проще промпт | хрупкий разбор, нельзя безопасно исполнять действия |

## Последствия

- SDK тянет HTTP-клиент, JSON-библиотеку и рантайм Kotlin в jar мода. На этапе 1 проверить размер и конфликты с другими модами. Если плохо — переходим на `HttpClient` за тем же интерфейсом `AiProvider`.
- Нужен API-ключ и бюджет ([вопрос 3](../open-questions.md)).
- Реплики игроков уходят во внешний сервис — игроков предупреждаем ([content-policy](../ops/content-policy.md)).
