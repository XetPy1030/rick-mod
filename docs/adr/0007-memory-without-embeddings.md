# 0007. Память без эмбеддингов: слоты, эпизоды и вспоминание по тегам

- **Статус:** принято
- **Дата:** 2026-09-26

## Контекст

Персонажи должны помнить игроков между сессиями ([memory](../architecture/memory.md)). Сырья много — летопись пишет сотни событий в неделю, а в промпт влезает несколько сотен токенов. Нужно выбирать, что вспомнить в конкретный момент. Ограничения: игроков 8, событий — тысячи, CPU — 3 ядра, бюджет — $2 в день; всё должно работать и без ключа API.

## Решение

- **Знания — слоты** с одним текущим значением и историей (`memory_fact`), обновляются кодом из итогов дня. Смена значения — сама по себе событие.
- **Эпизоды — события летописи** с важностью и тегами; забывание — полураспад по важности только в выдаче, в БД всё остаётся.
- **Вспоминание — детерминированная оценка**: важность × свежесть + совпадение тегов с ситуацией + «про этого игрока», в пределах бюджета символов маршрута.
- **ИИ — только для сжатия текста**: дневник дня и отношение персонажа пишет дешёвая модель ночью, одним запросом на всех ([каскад](../architecture/ai-integration.md#каскад-моделей)).

## Альтернативы

| Вариант | Плюсы | Минусы |
|---|---|---|
| **Слоты + эпизоды + теги** (выбрано) | бесплатно, микросекунды, объяснимо («почему Рик это вспомнил»), работает без ключа; смены слотов дают сюжет | теги надо проставлять; «похожесть по смыслу» только через теги |
| Эмбеддинги событий и поиск по сходству | находит связь по смыслу без тегов | платный запрос на каждое событие и каждый поиск, векторное хранилище, выдача не объяснима; для 8 игроков и событий с готовой структурой избыточно |
| Только саммари от модели («вот что ты знаешь об игроке») | просто, связный текст | модель теряет факты и путает их при пересжатии; каждое обновление — запрос; нечем выбрать «относящееся к моменту» |
| Всё подряд в промпт | ничего не теряется | цена растёт с историей, кеш префикса не помогает, модель тонет в деталях |

## Последствия

- Память работает и без ключа: слоты и эпизоды — код; без ИИ нет только дневника.
- Добавить новый вид воспоминаний — значит добавить тип события или слот, а не переучивать поиск.
- Если когда-нибудь понадобятся эмбеддинги (например, чтобы Рик вспоминал разговоры по смыслу на этапе 3), их можно добавить как ещё одно слагаемое в оценку, не ломая остальное.
