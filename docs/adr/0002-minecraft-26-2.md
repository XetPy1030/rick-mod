# 0002. Minecraft 26.2, Mojang-имена, Loom без ремапа

- **Статус:** принято
- **Дата:** 2026-09-26

## Контекст

Сервер планируется на 26.2. С 26.1 Minecraft Java не обфусцирован; Fabric перешёл на официальные имена Mojang и новый плагин Loom без ремапа, Yarn больше не поддерживается. На дату решения уже вышел 26.3, и Polymer, sgui и Fantasy под него тоже есть.

## Решение

- Целевая версия — **26.2**, Java 25.
- Сборка — плагин `net.fabricmc.fabric-loom` (Loom 1.17+), зависимости через `implementation`, итоговый артефакт — `jar`.
- Имена — официальные Mojang. Туториалы и примеры до 26.1 (Yarn-имена) не копируем без перевода имён.
- Переход на 26.3 — отдельным решением, когда появится причина: нужная фича игры, исправление или прекращение поддержки 26.2 библиотеками.

## Альтернативы

| Вариант | Плюсы | Минусы |
|---|---|---|
| Сразу 26.3 | самая свежая версия, дольше актуальна | сервер задуман под 26.2; версии библиотек под 26.3 моложе |
| 1.21.x | много старых туториалов | обфускация, Yarn, устаревшая версия |

## Последствия

- Простая сборка без ремапа, имена в коде совпадают с именами в игре и в стектрейсах.
- Меньше готовых туториалов на новых именах; опираемся на исходники Polymer и Fabric API под 26.2.
- Порт на 26.3 надо будет проверить отдельно, но все ключевые библиотеки уже выпущены.
