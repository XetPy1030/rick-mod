# Прогресс: репутация, титулы, достижения

> **Статус:** идея · **Этап:** 3–4

## Репутации

| Шкала | У кого | Диапазон | Этап |
|---|---|---|---|
| `science` | «Полезность для науки» у Рика | −100…+100 | 3 |
| `federation` | лояльность Федерации (во время оккупации) | −100…+100 | 7 |
| `citadel` | влияние в Цитадели (выборы) | 0…100 | 7 |
| `unity` | связь с Единством (финальный ивент) | 0…100 | 7 |

Уровни «Полезности для науки» — в [rick.md](characters/rick.md#репутация-полезность-для-науки).

## Титулы

Титул показывается префиксом в чате и таблисте. Активен один, выбирается `/rick title`.

| Титул | За что |
|---|---|
| Криперофил | 3 смерти от крипера подряд |
| Бессмертный наоборот | 10 смертей за сутки |
| Любимчик науки | «Полезность для науки» ≥ 90 |
| Подопытный № 1 | больше всех экспериментов Рика за неделю |
| Друг Мисиксов | Мисикс выполнил задачу за минуту |
| Огурчик | прошёл квест «Огурец» |
| Убийца с лицензией | 10 контрактов Кромбопулоса |
| Жертва Джерри | получил от Джерри бесполезную награду 5 раз |

Серии считаются по `player_stat_daily` ([storage](../architecture/storage.md)). Новые титулы — в этот список.

## Достижения

Кастомные достижения — data-driven JSON в датапаке мода, работают на ванильном клиенте. Иконки — ванильные предметы или Polymer-предметы.

| Достижение | Условие |
|---|---|
| Уаббалаббадабдаб | первый выстрел портальной пушкой |
| Я огурчик! | стать огурцом |
| Какова моя цель? | собрать масляного робота |
| Существование — боль | Мисикс ждал больше 20 минут |
| Покажи, что у тебя есть | участвовать в конкурсе головы в небе |
| Тело, дом, семья | выжить в кроненберг-апокалипсисе |
| Жизнь Роя | набрать 50+ лет в аркаде |
| Вне закона | пронести контрабанду через таможню |
