## Этап 1 — каркас

- [x] Gradle-проект: Loom 1.17+, Fabric API, jar-in-jar зависимости ([tech-stack](architecture/tech-stack.md))
- [x] Кастинг моделей OpenRouter: набор промптов, сводная таблица, выбор моделей по маршрутам ([ai-integration](architecture/ai-integration.md#кастинг-моделей))
- [x] Конфиг с фичефлагами и горячей перезагрузкой ([configuration](ops/configuration.md))
- [x] ИИ-клиент OpenRouter: маршруты с запасными моделями, отдельный пул потоков, таймауты, лимиты, дневной бюджет, учёт стоимости ([ai-integration](architecture/ai-integration.md))
- [x] Структурированный JSON-ответ и валидатор действий; на старте только `say` и `remember` ([ai-actions](architecture/ai-actions.md))
- [x] Хранилище: БД, миграции, таблица игроков, журнал ИИ-запросов ([storage](architecture/storage.md))
- [x] Реакции на смерть, вход и выход ([flavor](design/flavor.md)); вход считается после пароля EasyAuth
- [x] Адаптивная нагрузка: живые запросы флейвора встают при высоком MSPT сервера ([performance](architecture/performance.md#адаптивная-нагрузка)); spark для этого не понадобился
- [x] Проверка на полной копии сборки сервера, а не только в `runServer` ([tools/testserver](../tools/testserver/README.md)) — без живого клиента
- [x] Проверка живым клиентом: вход с паролем EasyAuth, смерть, выход, вид реплик в чате
- [x] Мод полностью работает без API-ключа: только заготовки
- [x] Роли игроков: таблица, команды `/rickadmin role …` и `/rick who`, роль в промпте и в заготовках ([player-roles](design/player-roles.md)); ключи пулов — с пулами на этапе 2
- [x] Команды `/rick off|on`, `/rickadmin reload`, `/rickadmin ai status` ([commands](ops/commands.md)); сверх плана — `/rick report` и разбор жалоб, `/rickadmin ai test`, `/rickdev`
- [x] Первая выкладка на сервер Millida, ключ OpenRouter ([server-setup](ops/server-setup.md))

**Готово, когда:** смерть игрока даёт комментарий в чате за ≤ 5 с; без ключа выводится заготовка; профиль не показывает заметного вклада мода в MSPT; расход токенов виден в `/rickadmin ai status`.

На копии сервера (2026-09-26): комментарий к смерти — за 2 с, приветствие и прощание — за 2–3 с; без ключа — заготовки; вклад мода ≈ 0,016 мс на тик ([замер](architecture/performance.md#замер-этапа-1)); расход и статистика по маршрутам — в `/rickadmin ai status`. Живым клиентом и на сервере проверено админом, роли игрокам назначены.

## Этап 2 — газета, MOTD, таблист

- [x] Летопись: что делал каждый игрок — ванильная статистика снимками, замеры, события; занятия, взаимодействия игроков, итоги дня, связи, прогнозы, профили ([chronicle](design/chronicle.md), [ADR 0006](adr/0006-chronicle-from-vanilla-stats.md))
- [x] Память Рика: эпизоды, знания-слоты, сюжетные линии, вспоминание по важности и свежести, дневник дня ([memory](architecture/memory.md), [ADR 0007](adr/0007-memory-without-embeddings.md))
- [x] Каскад моделей: дешёвый аналитик читает всё и готовит план номера, дорогая модель пишет ([ai-integration](architecture/ai-integration.md#каскад-моделей)); Batch API — с ночным батчем
- [x] Газета «Межпространственный вестник»: утром, `/rick news`, заголовок в чате при входе; без ключа — выпуск из фактов ([flavor](design/flavor.md#ежедневная-газета))
- [x] Анализ построек: где строят, что построено, рост, потери и кто был рядом, имена от аналитика ([builds](design/builds.md))
- [x] Ночной батч: пулы заготовок для смертей, приветствий, прощаний, MOTD и таблиста — пакетом Batch API, запасной путь — живые запросы ([пулы](architecture/ai-integration.md#пулы-заготовок))
- [x] MOTD и таблист с новостями других вселенных и заголовком газеты ([flavor](design/flavor.md#motd-и-таблист))
- [ ] Неделя на живом сервере

**Готово, когда:** неделя газет вышла без ручного вмешательства; батч укладывается в дневной бюджет; вклад летописи в тик не виден на профиле.

## Этап 2.5 — Рик в чате

- [x] Ответы на обращения, упоминания и ответы на реплики Рика; короткий разговор; лимиты и игнор ([chat](design/chat.md))
- [x] Маршрут `chat`: GPT-6 Sol, Luna в гонке; память об обидах и похвале — событием летописи
- [x] Редкие реакции в мире, которые выбирает код: отрыжка, метка, мусорный подарок ([ai-actions](architecture/ai-actions.md#реакции-чата-действие-выбирает-код))
- [ ] Неделя на живом сервере: промахи детектора, расход, не надоедает ли
- [ ] Подслушивание: Рик встревает в чужую переписку (`chat_overhear`)
- [ ] Инициатива: Рик сам цепляет игрока — редко, отдельный тип (`rick_initiative`)

**Готово, когда:** на обращение Рик отвечает за ≤ 5 с; на «Токсик Рик» и чужие разговоры не встревает; спамом его не выманить сверх лимитов; чат укладывается в `budget_share`.

Решения владельца — [№ 25–29](open-questions.md#решённые-2026-09-29-этап-3). Постройки и скин на этом этапе простые, эффектно — на этапе 3.5.

- [x] Ресурспак через Polymer autohost — перенесён с этапа 4: без пака у манекена нет скина ([content-delivery](architecture/content-delivery.md))
- [ ] Спайк манекенов: скин из ресурспака виден у игроков с их лаунчерами, подпись «NPC» скрыта ([server-integration](architecture/server-integration.md#скины)) — сервер проверен, нужен живой клиент
- [x] Генератор скинов `tools/skins/`, простой скин Рика
- [x] Хаб-измерение Цитадель, простая лаборатория из NBT: генерирует скрипт, админ может перестроить ([worlds](architecture/worlds.md#цитадель))
- [x] Портал по вызову: «рик, забери меня» и `/rick citadel`, возврат туда, откуда пришёл
- [x] NPC Рика: манекен в лаборатории, разговор по ПКМ, общая память с чатом ([rick](design/characters/rick.md))
- [x] Репутация «Полезность для науки»: шкала, уровни, тон Рика
- [x] Действия `change_reputation`, `give_quest`, `complete_quest`, `give_item` — по контракту ([ai-actions](architecture/ai-actions.md)); `take_item` не нужен — предметы для заданий забирает код
- [x] Таблица наград: ванильные ресурсы и именные артефакты, лимиты в сутки
- [x] Ежедневный эксперимент и первые простые квесты: принеси, набери статистику ([quests](design/quests.md))
- [x] Контекст Origins: раса игрока в промпте
- [ ] Мост в FTB Quests: глава «Задания Рика» через `tree.py` — достижения мода готовы
- [ ] Манекены мода — в чёрный список Carry On
- [x] Образцы голоса → [№ 17](open-questions.md#решённые-2026-09-29-этап-3): `gpt-audio-mini`, голос `ash`
- [ ] Озвучка реплик Рика через Simple Voice Chat ([voice](design/voice.md))

**Готово, когда:** Рик помнит игрока между сессиями, выдаёт и принимает квест, а попытки уговорить его выдать что-то сверх белого списка ничего не дают.

## Этап 3.5 — Цитадель эффектно

- Постройки Цитадели: лаборатория, площадь, места под торговца и аркады — максимально эффектно
- Скин Рика и будущих персонажей — детально
- Портал: вид, звук, частицы

**Готово, когда:** в Цитадель хочется зайти просто посмотреть.

## Этап 4 — Polymer и гаджеты

- Пайплайн ассетов для предметов и моделей ([content-delivery](architecture/content-delivery.md)); сам ресурспак появляется на этапе 3
- Портальная жидкость и шмекели ([items](design/items.md), [economy](design/economy.md))
- Портальная пушка
- Простые гаджеты: переводчик для животных, уменьшающий луч, плюмбус
- Первые кастомные достижения ([progression](design/progression.md))

**Готово, когда:** клиент сборки видит модели, пак скачивается автоматически, гаджеты работают без изменений клиентской сборки, JEI не ломается на Polymer-предметах.

- Движок визитов: портал, 5–10 минут, уход ([visitors](design/characters/visitors.md))
- Разговор с персонажами голосом ([voice](design/voice.md))
