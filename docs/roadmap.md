## Этап 1 — каркас

- [x] Gradle-проект: Loom 1.17+, Fabric API, jar-in-jar зависимости ([tech-stack](architecture/tech-stack.md))
- [x] Кастинг моделей OpenRouter: набор промптов, сводная таблица, выбор моделей по маршрутам ([ai-integration](architecture/ai-integration.md#кастинг-моделей))
- [x] Конфиг с фичефлагами и горячей перезагрузкой ([configuration](ops/configuration.md))
- [x] ИИ-клиент OpenRouter: маршруты с запасными моделями, отдельный пул потоков, таймауты, лимиты, дневной бюджет, учёт стоимости ([ai-integration](architecture/ai-integration.md))
- [x] Структурированный JSON-ответ и валидатор действий; на старте только `say` и `remember` ([ai-actions](architecture/ai-actions.md))
- [x] Хранилище: БД, миграции, таблица игроков, журнал ИИ-запросов ([storage](architecture/storage.md))
- [x] Реакции на смерть, вход и выход ([flavor](design/flavor.md)); вход считается после пароля EasyAuth
- [x] Адаптивная нагрузка: живые запросы флейвора встают при высоком MSPT сервера ([performance](architecture/performance.md#адаптивная-нагрузка)); spark для этого не понадобился
- [x] Проверка на полной копии сборки сервера, а не только в `runServer` ([tools/testserver](../tools/testserver/README.md)) — без живого клиента
- [x] Проверка живым клиентом: вход с паролем EasyAuth, смерть, выход, вид реплик в чате
- [x] Мод полностью работает без API-ключа: только заготовки
- [x] Роли игроков: таблица, команды `/rickadmin role …` и `/rick who`, роль в промпте и в заготовках ([player-roles](design/player-roles.md)); ключи пулов — с пулами на этапе 2
- [x] Команды `/rick off|on`, `/rickadmin reload`, `/rickadmin ai status` ([commands](ops/commands.md)); сверх плана — `/rick report` и разбор жалоб, `/rickadmin ai test`, `/rickdev`
- [x] Первая выкладка на сервер Millida, ключ OpenRouter ([server-setup](ops/server-setup.md))

**Готово, когда:** смерть игрока даёт комментарий в чате за ≤ 5 с; без ключа выводится заготовка; профиль не показывает заметного вклада мода в MSPT; расход токенов виден в `/rickadmin ai status`.

На копии сервера (2026-09-26): комментарий к смерти — за 2 с, приветствие и прощание — за 2–3 с; без ключа — заготовки; вклад мода ≈ 0,016 мс на тик ([замер](architecture/performance.md#замер-этапа-1)); расход и статистика по маршрутам — в `/rickadmin ai status`. Живым клиентом и на сервере проверено админом, роли игрокам назначены.

## Этап 2 — газета, MOTD, таблист

- [x] Летопись: что делал каждый игрок — ванильная статистика снимками, замеры, события; занятия, взаимодействия игроков, итоги дня, связи, прогнозы, профили ([chronicle](design/chronicle.md), [ADR 0006](adr/0006-chronicle-from-vanilla-stats.md))
- [ ] Память Рика: эпизоды, знания-слоты, сюжетные линии, вспоминание по важности и свежести ([memory](architecture/memory.md))
- [ ] Каскад моделей: дешёвый аналитик читает всё и готовит бриф, дорогая модель пишет ([ai-integration](architecture/ai-integration.md#каскад-моделей))
- [ ] Газета «Межпространственный вестник»: утром, `/rick news`, заголовок в чате при входе; без ключа — выпуск из фактов
- [ ] Анализ построек: где строят, что построено, рост за неделю, подозрение на гриф ([builds](design/builds.md))
- [ ] Ночной батч: пулы заготовок для смертей, приветствий, MOTD, новостей
- [ ] MOTD и таблист с новостями других вселенных
- [ ] Неделя на живом сервере

**Готово, когда:** неделя газет вышла без ручного вмешательства; батч укладывается в дневной бюджет; вклад летописи в тик не виден на профиле.

## Этап 3 — Рик в Цитадели

- Хаб-измерение Цитадель, постройка из NBT ([worlds](architecture/worlds.md))
- Спайк манекенов: скин из ресурспака виден у игроков с их лаунчерами, подпись «NPC» скрыта ([server-integration](architecture/server-integration.md#скины))
- Генератор скинов `tools/skins/`, скин Рика
- NPC Рика: внешний вид, разговор по ПКМ, память, репутация «Полезность для науки» ([rick](design/characters/rick.md))
- Голос Рика: озвучка реплик через Simple Voice Chat ([voice](design/voice.md))
- Контекст Origins: раса игрока в промпте, смена расы как награда
- Мост в FTB Quests: глава «Задания Рика»
- NPC и сущности мода — в чёрный список Carry On
- Действия `give_quest`, `change_reputation`, `give_item` (только из таблицы наград)
- Ежедневные эксперименты и первые простые квесты ([quests](design/quests.md))

**Готово, когда:** Рик помнит игрока между сессиями, выдаёт и принимает квест, а попытки уговорить его выдать что-то сверх белого списка ничего не дают.

## Этап 4 — Polymer и гаджеты

- Polymer, autohost ресурспака, пайплайн ассетов ([content-delivery](architecture/content-delivery.md))
- Портальная жидкость и шмекели ([items](design/items.md), [economy](design/economy.md))
- Портальная пушка
- Простые гаджеты: переводчик для животных, уменьшающий луч, плюмбус
- Первые кастомные достижения ([progression](design/progression.md))

**Готово, когда:** клиент сборки видит модели, пак скачивается автоматически, гаджеты работают без изменений клиентской сборки, JEI не ломается на Polymer-предметах.

## Этап 5 — визиты и персонажи

- Движок визитов: портал, 5–10 минут, уход ([visitors](design/characters/visitors.md))
- Разговор с персонажами голосом ([voice](design/voice.md))
- Морти, Джерри, Птицечеловек, Страшный Терри, Мисиксы, Кромбопулос Майкл
- Инопланетный торговец с ассортиментом от ИИ ([economy](design/economy.md))
- Межпространственный ТВ, масляный робот, микровселенная-батарея

**Готово, когда:** визиты случаются сами, не мешают игре, укладываются в лимиты API и CPU.
