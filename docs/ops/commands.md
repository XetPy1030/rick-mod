# Команды

> **Статус:** команды этапов 1–2 и Цитадели этапа 3 реализованы · **Этап:** 1+
>
> Код: `ru.xetpy.rikoshet.command`.

## Игроки

| Команда | Что делает | Этап |
|---|---|---|
| `/rick off` / `/rick on` | выключить или включить ИИ-персонажей и упоминания себя: Рик не пишет тебе, не комментирует тебя и не упоминает в промптах о других | 1 |
| `/rick who` | кто есть кто: ники онлайн с ролями, у кого роли нет — «вариант неизвестно откуда» ([player-roles](../design/player-roles.md)) | 1 |
| `/rick` | короткая справка: что умеют персонажи, как выключить | 1 |
| `/rick me` | карточка из [летописи](../design/chronicle.md): сколько сегодня в игре и чем занимался, заметные числа, стиль за две недели, с кем чаще всего, главная угроза, обычный час, главная постройка. С `/rick off` — не ведётся | 2 |
| `/rick news` | свежий выпуск «Межпространственного вестника» целиком ([газета](../design/flavor.md#ежедневная-газета)) | 2 |
| `/rick citadel` | Рик открывает портал в Цитадель рядом с игроком, на 15 с. То же — «рик, забери меня» в чате ([worlds](../architecture/worlds.md#цитадель)) | 3 |
| `/rick science` | «Полезность для науки», уровень, задания Рика и прогресс по ним, сколько экспериментов сдано ([quests](../design/quests.md)) | 3 |
| `/rick title [id]` | выбрать титул | 4 |
| `/rick shrink allow\|deny` | разрешить или запретить уменьшать себя лучом | 4 |
| `/rick voice off` / `on` | выключить или включить голосовой ввод и озвучку для себя ([voice](../design/voice.md)) | 3 |
| `/rick report [комментарий]` | пожаловаться на последнюю реплику ИИ, которую ты видел: пишется в БД, админам онлайн — сразу в чат | 1 |

## Админы

| Команда | Что делает | Этап |
|---|---|---|
| `/rickadmin reload` | перечитать конфиг, ключ, промпты и заготовки; конфиг с ошибками не применяется | 1 |
| `/rickadmin ai status` | состояние ИИ и источник ключа, расход за сутки, запросы в минуту, очередь, MSPT и уровень нагрузки, EasyAuth; по маршрутам с запуска — запросы, доля OK, p50 и p90 задержки, попытки, стоимость, доля кеша, последняя ошибка; неразобранные жалобы | 1 |
| `/rickadmin ai test flavor <контекст…>` | живой запрос флейвора с твоим контекстом вместо события: видно ответ, модель, цену, задержку | 1 |
| `/rickadmin ai test dialogue <реплика…>` | то же для диалога: `say`, `mood`, какие действия прошли белый список и какие отклонены. Действия не применяются | 1 |
| `/rickadmin report list` | 20 старейших неразобранных жалоб: кто, на какую реплику, комментарий | 1 |
| `/rickadmin report resolve <id>\|all` | пометить жалобу разобранной | 1 |
| `/rickadmin role set <ник> <название…>` | назначить роль, до 48 символов; архетип определяется по названию | 1 |
| `/rickadmin role note <ник> <текст…>` | описание роли для ИИ, до 200 символов; `-` стирает | 1 |
| `/rickadmin role archetype <ник> <rick\|morty\|jerry\|summer\|beth\|other>` | переопределить архетип | 1 |
| `/rickadmin role clear <ник>` / `role list` | снять роль / список всех ролей | 1 |
| `/rickadmin ai pause` / `resume` | глобально выключить или включить живые запросы | 1 |
| `/rickadmin chronicle status` | включена ли летопись, какой день ведёт, за кем следит, сколько домов найдено | 2 |
| `/rickadmin chronicle day [ГГГГ-ММ-ДД]` | пересчитать итоги дня (по умолчанию вчера) и показать сводку, как её увидит редакция газеты; текст — и в лог | 2 |
| `/rickadmin chronicle player <ник>` | карточка игрока, итог прошлой сессии, счётчики за всё время | 2 |
| `/rickadmin chat status` | Рик в чате: ответов с запуска, сколько промолчал и отброшено лимитами, разговоры сейчас, кто в игноре ([chat](../design/chat.md)) | 2.5 |
| `/rickadmin pool status` | пулы заготовок: живых реплик / запас по каждому ключу, идёт ли генерация ([пулы](../architecture/ai-integration.md#пулы-заготовок)) | 2 |
| `/rickadmin pool regen [live]` | досчитать пулы сейчас: пакетом (результат через минуты) или `live` — живыми запросами | 2 |
| `/rickadmin news publish [ГГГГ-ММ-ДД]` | выпустить газету за день (по умолчанию вчера) вне расписания и разослать; показывает выпуск, модель и цену | 2 |
| `/rickadmin news preview [ГГГГ-ММ-ДД]` | собрать выпуск и показать только себе, не публикуя; ИИ-запросы при этом тратят бюджет | 2 |
| `/rickadmin builds` | 15 самых больших построек: координаты, хозяин, рукотворных блоков, имя, виды блоков; сколько в очереди скана ([builds](../design/builds.md)) | 2 |
| `/rickadmin builds scan <x> <z>` | поставить клетку с этими координатами в очередь скана сейчас (измерение — где стоит админ; из консоли — Верхний мир) | 2 |
| `/rickadmin memory show <ник>` | что Рик знает об игроке (слоты, сюжетные линии) и что вспомнит при входе ([memory](../architecture/memory.md)) | 2 |
| `/rickadmin memory forget <ник>` | стереть знания и эпизоды игрока; счётчики летописи остаются | 2 |
| `/rickadmin citadel status` | Цитадель: включена ли, готова ли, точки, игроки в ней, открытые порталы, разговоры с Риком, эксперимент дня | 3 |
| `/rickadmin citadel tp` | в Цитадель без портала и обратно | 3 |
| `/rickadmin citadel mark rick\|spawn\|portal_back` | сдвинуть точку туда, где стоит админ, и повернуть по его взгляду; до `save` — в БД | 3 |
| `/rickadmin citadel save` | сохранить лабораторию, перестроенную в креативе: точки встают в неё структурными блоками, файл — `world/generated/rikoshet/structures/citadel/lab.nbt` | 3 |
| `/rickadmin citadel place` | поставить лабораторию заново поверх нынешней (из сохранённой, если есть) | 3 |
| `/rickadmin rep <ник> <изменение>` | поправить «Полезность для науки»; пишется в журнал с источником `admin` | 3 |
| `/rickadmin persona mute <id>` | заглушить персонажа | 4+ |
| `/rickadmin visit <persona> <player>` | вызвать визит вручную | 5 |
| `/rickadmin event schedule <id> <дата>` | назначить ивент; анонс уходит за сутки | 7 |
| `/rickadmin event list\|start\|pause\|skip\|stop <id>` | управление ивентами | 7 |
| `/rickadmin rollback <event>` | откатить изменения ивента по реестру | 7 |

Ник в `role …` ищется среди игроков онлайн, потом в БД, потом в ролях. Роль можно дать и тому, кто ещё не заходил: сервер в оффлайн-режиме, UUID считается от ника. Регистр ника важен — `Dimon` и `dimon` дают разные UUID.

Админ с неразобранными жалобами при входе получает напоминание.

## Отладка

Только с флагом запуска `-Drikoshet.dev=true` ([configuration](configuration.md#флаги-запуска)); на боевом сервере команды нет. Нужны op 3. События идут от фейковых игроков — живой клиент не нужен.

| Команда | Что делает |
|---|---|
| `/rickdev join <ник>` | вход после пароля: приветствие |
| `/rickdev death <ник> <тип_урона> [убийца]` | смерть: тип — id из реестра (`minecraft:lava`), убийца — сущность (`minecraft:creeper`) или ник |
| `/rickdev leave <ник>` | выход: прощание через `leave_delay_seconds` |
| `/rickdev chat test <текст…>` | как детектор понял фразу: обращение, упоминание или ничего |
| `/rickdev chat say <ник> <текст…>` | сообщение в чат от фейкового игрока: летопись и Рик видят его как настоящее |
| `/rickdev chat react <ник> burp\|glow\|gift` | реакция чата на фейковом игроке без шанса и лимитов |
| `/rickdev chronicle stat <ник> <число> <ключ>` | прибавить фейковому игроку ванильный счётчик: ключ летописи — `mined:diamond_ore`, `dropped:diamond`, `custom:deaths` |
| `/rickdev chronicle move <ник> <x> <z>` | переставить фейкового игрока (высота — по карте высот, у незагруженного чанка — 100) |
| `/rickdev chronicle chat <ник> <текст…>` | сообщение в чат для счётчиков летописи; в чат не выводится |
| `/rickdev chronicle cycle` | замер и снимок всех сейчас, не дожидаясь `snapshot_minutes` |
| `/rickdev chronicle analyze <ГГГГ-ММ-ДД>` | итоги дня — в лог |
| `/rickdev citadel npc` | поставить Рика в лаборатории без игрока в Цитадели; ответ — UUID и место |
| `/rickdev talk <ник> [текст…]` | разговор с Риком от фейкового игрока, стоящего в двух блоках перед ним: без текста — ПКМ, с текстом — реплика. Запрос к ИИ целиком пишется в лог |
| `/rickdev give <ник> <число> <предмет>` | положить предметы фейковому игроку в Цитадели — проверить сдачу заданий |

Фейковые игроки не входят в список игроков: пустой сервер через `pause-when-empty-seconds` встаёт на паузу. Для событий это не помеха, для замеров нагрузки и летописи — помеха ([performance](../architecture/performance.md#профилирование)): замеры и снимки идут по тикам.

## Права

Решено ([№ 15](../open-questions.md)): оп только у админа (XetPy), у игроков уровень 0.

- `/rick …` — доступны всем.
- `/rickadmin …` — требуют op уровня 3. Мод на права (LuckPerms и т. п.) не нужен.
- Команды выполняются и из консоли панели — для случаев, когда админ не в игре.
- До входа по паролю EasyAuth команды игроку недоступны ([server-integration](../architecture/server-integration.md#моды-и-что-с-ними-делаем)).
