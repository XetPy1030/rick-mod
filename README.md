# Rick Mod

Серверный Fabric-мод для приватного сервера друзей: вселенная «Рика и Морти» в Minecraft с ИИ-персонажами, гаджетами, квестами и ивентами. Контент 18+.

Игрокам ничего не нужно ставить: клиент ванильный, кастомные предметы и модели приходят через ресурспак, который сервер отдаёт при входе.

> Рабочее название. Некоммерческий фан-проект, не связан с правообладателями сериала, Mojang или Microsoft.

## Статус

**Этап 0 — документация.** Кода пока нет. План — в [дорожной карте](docs/roadmap.md).

## Платформа

| | |
|---|---|
| Minecraft | 26.2, Java Edition, выделенный сервер |
| Загрузчик | Fabric Loader 0.19.x + Fabric API |
| Java | 25 |
| Серверный контент | Polymer + autohost ресурспака |
| ИИ | облачный API, асинхронные запросы, ответы в JSON |

Точные версии и изменения в 26.x — в [tech-stack.md](docs/architecture/tech-stack.md).
