# Рикошет

Серверный Fabric-мод по «Рику и Морти» для сервера друзей «Vanilla+ 26.2»: ИИ-персонажи с памятью и голосом, гаджеты, квесты и межпространственные ивенты. Контент 18+.

Мод стоит только на сервере. Клиентскую сборку трогать не нужно: кастомные предметы, модели и скины персонажей приходят через ресурспак, который сервер отдаёт при входе.

- `mod_id`: `rikoshet`, пакет `ru.xetpy.rikoshet`
- Автор: XetPy

> Некоммерческий фан-проект, не связан с правообладателями сериала, Mojang или Microsoft.

## Статус

**Этап 0 — документация — готов.** Кода пока нет, следующий шаг — каркас (этап 1). План — в [дорожной карте](docs/roadmap.md).

## Платформа

| | |
|---|---|
| Minecraft | 26.2, Java Edition, выделенный сервер |
| Загрузчик | Fabric Loader 0.19.5 + Fabric API |
| Java | 25 |
| Серверный контент | Polymer + autohost ресурспака |
| ИИ | OpenRouter, несколько моделей по задачам, ответы в JSON |
| Голос | Simple Voice Chat API: персонажи говорят вслух |

Точные версии и изменения в 26.x — в [tech-stack](docs/architecture/tech-stack.md), сервер и его моды — в [server-integration](docs/architecture/server-integration.md).
